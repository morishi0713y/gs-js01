# 質問トレーナー

## 説明
企業説明会の質疑応答を、3択クイズで練習できるWebアプリです。

## URL
https://morishi0713y.github.io/gs-js01/quiz.html

## 工夫した点
- じゃんけんの仕組み（コンピュータの手 → 問題、グー・チョキ・パー → 選択肢、勝敗 → コメント）を応用して作りました。
- 「正解・不正解」ではなく、選んだ質問や態度が相手からどう見えるかをコメントで返すようにしました。
- 問題を出す前は選択肢を隠し、選んだボタンには色が付くようにして、コメントはフェードインで表示しました。

## 次回トライしたいこと
- 問題の数を増やして、配列でまとめて管理したい。
- 選択肢ごとに同じような処理を書いているので、関数にまとめたい。

## 備考
- index.html（おみくじ）と janken.html（じゃんけん）は授業の練習で作ったものです。
